# Indian Girls Wallpaper

Native Android wallpaper gallery built with Kotlin.

## Features
- Search wallpapers by title or category
- Traditional, Saree, Lehenga, Bridal and Modern categories
- Two-column image gallery and full-screen preview
- Download images to Pictures/IndianGirlsWallpaper
- Set an image as the device wallpaper
- Share wallpaper links
- BHAGRAJ branding

Images are loaded from Unsplash URLs and require internet access. Before publishing, replace sample images with images you own or are licensed to distribute.

## Build APK
GitHub Actions builds a debug APK on pushes to main and on manual runs.
Open Actions, select Android Debug APK, open the latest successful run, and download the Indian-Girls-Wallpaper-debug-apk artifact.

The debug APK is for testing. A Play Store release requires a signed release build and a privacy policy.
